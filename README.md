# OSINT

Meie projekt on OSINT-koondaja, mis kogub kasutaja sisestatud domeeni kohta avalikest allikatest infot ja esitab selle ühtse ülevaatena. Programm aitab leida näiteks domeeni registreerimisandmeid, IP-aadresse ning domeeni meilinduse, sealhulgas meiliserverite ja e-posti turvaseadistuste kohta käivat infot. Projekt lahendab probleemi, et need andmed on eri allikates laiali ning nende käsitsi otsimine võtab aega. Valisime selle projekti, sest meid huvitavad küberturvalisus ja avaliku info leidmine ning soovime õppida, kuidas programmiga eri allikatest andmeid koguda ja töödelda.
